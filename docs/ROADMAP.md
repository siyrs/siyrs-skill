# Roadmap

The following commands are intentionally not active in v0.1.x.

## Candidate v0.2.x

- `/siyk-project-audit` — industrial architecture/function/test/security audit with P0/P1/P2 findings.
- `/siyk-code-review` — review current diff/branch with actionable fixes and regression evidence.
- `/siyk-ci-fix` — reproduce and repair CI failures, then persist test coverage.

## Candidate v0.3.x

- `/siyk-release` — versioning, changelog, artifacts, tags, release checks.
- `/siyk-deploy-check` — deployment readiness and rollback verification without deploying by default.
- `/siyk-doc-sync` — synchronize implementation, API, schema, runbook, and user documentation.

## Later

- project-specific policy packs;
- Android device/emulator matrix adapter;
- browser-driven UAT evidence adapter;
- GitHub/GitLab PR/MR adapters;
- eval suite for model-routing and workflow-compliance behavior.
