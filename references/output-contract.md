# Output contract

Use compact evidence-first reports.

## Test reports

Include status; workflow/tier; config validation and resolved plan; project/modules; baseline/fingerprint/tree; direct/expanded scope; selector and case IDs; exact commands/outcomes; pass/fail/skipped/blocked; coverage; failure classification; UAT planned versus executed; state/evidence path; debt/risks; T3 release decision.

## Git commit

Include embedded T1 plan/evidence; staged candidate tree; deterministic Index audit; redacted risk ledger; hook/restage actions; T1 promotion result; commit/no-op; remaining worktree; and confirmation that the remote was not contacted.

## Git sync

Include explicit current/target branch (`--branch` when provided), embedded commit, fetch/divergence/integration/conflicts, post-integration T1 and optional PR T2, outgoing base/head audit, risk ledger, push/PR result, and remaining risks.

Never fabricate evidence or reveal complete secret values.
